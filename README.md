# Smart Secure File Archiver (`SARC v1.0`)

Інтелектуальний криптографічно захищений багатотомний архіватор файлів на **.NET 10 (C#)**, що поєднує класичні алгоритми стиснення без втрат (**LZ77 + канонічний код Гаффмана**), комбінаторну оптимізацію пакування томів (**0/1 Knapsack ДП + Генетичний алгоритм**), нейромережевий преаналіз даних (**MLP**) та автентифіковане шифрування за схемою **Encrypt-then-MAC (AES-256-CTR + HMAC-SHA256)**.

---

## Ключові можливості

* **Нейромережевий преаналіз (MLP `2 -> 5 -> 5 -> 1`):** обчислює нормалізовану ентропію Шеннона та частку друкованих ASCII-символів для кожного блоку, автоматично вимикаючи стиснення (`NO_COMPRESSION`) для вже стиснутих або зашифрованих даних.
* **Двоступеневе стиснення (LZ77 + Canonical Huffman):**
  * **LZ77:** підтримка жадібного (`CompressGreedy`) та лінивого (`CompressLazy`) розбору зі змінним вікном пошуку.
  * **Канонічне кодування Гаффмана:** серіалізація дерева лише через масив довжин кодів (`256` байтів) із коректною обробкою виродженого алфавіту.
* **Оптимізація багатотомного пакування:**
  * **Динамічне програмування (0/1 Knapsack):** точне заповнення томів обмеженої місткості за сумарною цінністю блоків.
  * **Генетичний алгоритм (GA):** автоматичний підбір гіперпараметрів компресора (`WindowSize`, `MinMatch`, `EntropyThreshold`) та порівняння з випадковим пошуком.
* **Криптографічний захист (`SARC v1.0`):**
  * Деривація ключів через **PBKDF2-HMAC-SHA256** (`K_enc`, `K_mac`).
  * Шифрування **AES-256-CTR** + контроль цілісності **HMAC-SHA256** та контрольна сума **CRC32** кожного блоку.
  * Модулі моделювання атак (`AttackModule`) для перевірки стійкості до підміни байтів, обрізання архіву та невірного пароля.
